# OpenWrt F50 插件 v0.1.0 · 实验性预发布

首个版本化下载，适合试用、审阅与继续开发。

## 本版内容

- Added independent IPv6 RA refresh and Xiaojing IoT calibration source packages.
- Added optional LuCI interfaces, disabled defaults, installation guidance and isolated checks.

## 下载选择

| 文件 | 内容 |
| --- | --- |
| `openwrt-f50-plugins-v0.1.0-source.zip` | 四个包的完整源码、测试和文档 |

下载后先解压并阅读 README。完整源码包适合开发，按功能拆分的包方便按需取用。

## 已验证与限制

Python 静态/RA 模拟检查和 Ruby 小鲸隔离测试通过；现有设备集成截图不等于独立包安装验收。

仅提供源码，不能直接通过 opkg/apk 安装。目标固件 SDK 构建、依赖解析、首次安装/升级/卸载、开机生命周期和独立 LuCI 页面实机验收仍待完成。

## 升级与数据

本次不修改查询协议或后台业务逻辑。更新前自行保存配置；保留设备上的私有配置和原流量池历史；同名私人服务需先评估冲突。

校验附件：macOS 用 `shasum -a 256 -c SHA256SUMS.txt`；Linux 用 `sha256sum -c SHA256SUMS.txt`。请将本次所有附件下载至同一目录再校验。
