# OpenWrt F50 插件 v0.1.1 · 实验性预发布

本版将 F50 本机的自适应 RA 刷新逻辑移植为可配置公开插件。RA 后台和对应 LuCI 包为 0.1.1，小鲸代码与包版本仍为 0.1.0。

## 更新内容

- 按已知寿命的四分之一提前请求，最少 30 秒、最多 7200 秒，且受配置阈值上限约束。平时每分钟观察，剩余不足 240 秒时每 10 秒观察。
- 增加自然续期间隔的采样估计，区分网关通告寿命和观察下界；样本不足返回 null，界面显示尚未测得。
- 请求后核验路由真正续期；仅 rdisc6 退出成功不再算续期成功。
- 重启、接口或网关变更后重新学习；本脚本的主动请求不计入自然周期。
- 保留默认关闭、WAN/网卡校验、UCI 配置、原有 JSON 字段与 CLI；增加 adaptive=0 以使用旧固定策略。

## 兼容性与验收边界

总开关仍默认关闭。旧配置中缺少 adaptive 时按 1 处理；已启用的服务更新后会采用自适应观察，原 interval 仅在 adaptive=0 时生效，threshold 在自适应时是上限。请保存配置，再按安装文档升级对应后台和 LuCI。

隔离测试覆盖策略、自然/主动续期区分、真实续期核验、状态损坏、身份变化及旧固定模式。F50 本机部署脚本已有网关 65535 秒寿命的实测记录；公开包的 SDK 构建、全新安装/升级/卸载和独立 LuCI 实机交互仍未验收。本次发布没有改动生产设备。

自然续期是约一分钟分辨率的采样推断，不保证观察到每个 RA；其他进程的 RS 也可能被计入。学习状态只存 /var/run，重启重新学习。不删路由、不手工延寿、不改 DNS、不重拨或重启网络。

所有附件下载到同一目录后，macOS 用 `shasum -a 256 -c SHA256SUMS.txt`，Linux 用 `sha256sum -c SHA256SUMS.txt` 校验。
