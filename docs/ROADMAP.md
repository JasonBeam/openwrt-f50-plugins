# 距离稳定可维护版本还差什么

最新已发布版本为 v0.1.1 实验性预发布；main 另含 2026-10-22 新增的 MU300 集成版间隔补丁，尚未收录到新 Release。Release 解决按版本下载与追溯，不能替代真实环境验收。

## 建议的打包顺序

先完成 `f50-ra-refresh` 与对应 LuCI 的 SDK 构建，确认 `rdisc6` 的提供方式后在测试设备验收；再在有兼容 `unisoc.traffic` 的固件上验证小鲸后台与 LuCI。两项功能分别发布，已有集成版补丁暂不包装成通用安装包。

格式由目标固件实际使用的 opkg / apk 与匹配 SDK 决定，不按 F50 型号猜测。具体依赖、构建入口和安装包发布条件见[打包建议](PACKAGING.md)。

## 稳定版前的主要验收

- [ ] 固定目标固件版本、SDK、架构和软件包格式，真正构建 IPK/APK。
- [ ] 在测试设备验收首次安装、依赖、启用、开机、停用、升级及卸载。
- [ ] 验收独立 LuCI 页面的 rpcd 权限、交互及手机/桌面布局。
- [ ] 验证真实小鲸接口、HTTPS 可用性、失败保留及换卡行为。
- [ ] 验证正确 WAN 上的 RS/RA 交互，不以路由存在代替刷新成功。
- [ ] 完成以上流程后再发布注明固件兼容范围的可安装包。

## 已补齐的协作基础

- 版本化 Release、用途明确的附件与 SHA-256 校验。
- 源码自动测试与自动打包，附件只取已提交文件。
- CHANGELOG、问题模板、贡献和安全说明。

后续按真实反馈确定优先级，不承诺未验证平台兼容性，也不以截图或 CI 绿灯代替完整验收。
