# 本地代码审查与验收边界

日期：2026-10-16。范围：本仓库的分享版源码，而不是对其他固件的通用安全背书。
本轮由 Codex 在本地审查并修正；没有把它描述为多个真人或独立审查员签字。

## 已发现并处理的发布问题

| 问题 | 处理 |
| --- | --- |
| 私人脚本不适合直接共享 | 重新整理成四个独立包目录，仅提供空配置示例，不附带任何设备备份 |
| 默认启用可能误改他人的流量池/网络行为 | 两个功能默认关闭；手动同步也要求明确启用 |
| 小鲸接口使用 HTTP 的隐私风险不明显 | HTTPS 默认、不自动降级；HTTP 必须在界面明确选择并告知风险 |
| 状态或日志可能泄露凭据 | 状态字段白名单；凭据不进入命令行，不读回前端；文件 0600、目录 0700 |
| 换卡后可能仍显示旧卡余量 | 同锁下更换配置，先使平台快照失效；不清空原计费历史 |
| 定时与手动重复校正 | 两条入口共享内核 flock；同步期间不能更改账号 |
| 非兼容固件可能错误调用校正 | 查询运营商前检查 unisoc.traffic/get 的配置形状；set 失败不标为成功 |
| RA 写死私人网络 | 逻辑 WAN、网卡前缀、阈值、间隔可配置并验证；默认限制蜂窝网卡 |
| 缺少工具或接口错误时贸然改网络 | 只提示，绝不删路由、改 DNS 或重启网络 |
| 包含私人 rdisc6 二进制的架构/来源风险 | 不捆绑，明确由使用者提供可信且匹配架构的工具 |
| 开源范围和许可不明确 | 新编写分享版采用 MIT；外部依赖许可独立，不复制整个固件页面 |

## 本轮验证

- Ruby、Shell、JavaScript 语法检查。
- RA 模拟命令测试：默认关闭、健康寿命、低寿命、路由缺失、非蜂窝接口、未知寿命、非法配置及只读状态；禁止任何路由修改命令。
- JSON、默认停用、无通配 RPC 权限和源码发布边界检查。
- 小鲸隔离测试：禁用状态不查询、非法配置拒绝、私有权限、成功校正、未知选项保留、失败不校正、快照保留、并发锁、只读预览、底层 set 失败、换卡失效和验证码不串用。
- 测试卡号为虚构数据；不会请求真实运营商或改动生产流量池。

## 仍需验证，不应略过

1. 对应 OpenWrt SDK 的真正 APK/IPK 构建、依赖解析及首次安装/升级/卸载。
2. 新建 LuCI 页面的真实 rpcd 权限、手机/桌面布局和所有交互。
3. 完整开机、停用以及配置变更的服务生命周期。
4. 真实运营商接口的当前响应格式、HTTPS 可用性以及 HTTP 风险确认。
5. 正确 WAN 上的 RS/RA 交互及服务商响应；不是只检查工具存在。

## 无法消除的边界

- 查询成功不保证平台账单实时；1024 MB/GB 显示口径与本机字节计数存在差异。
- 平台可能在接口不变时改变额度、验证码或登录要求，失败必须停在不校正状态。
- 流量池 set 成功后若本地状态落盘失败，账本可能已校正但状态未更新；没有跨进程分布式事务保证，不能仅凭缓存判断完全未改动。
- 程序异常、电源中断或磁盘故障仍可能影响文件保存，不能承诺零风险。
- RA 刷新不等于修复 Wi-Fi 队列、SIPA 硬件卸载或整机重启。

此版只作为实验性源码公开。通过源码测试不等于可直接部署到任意生产路由器。
