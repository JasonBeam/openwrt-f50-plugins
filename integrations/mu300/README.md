# 已有 MU300 流量池集成版：自定义小鲸刷新间隔

2026-10-22 新增。此目录为已有私人集成部署的兼容补丁，**不是独立插件的安装器**。
独立 `luci-app-f50-xiaojing` 页面本来就提供 300–86400 秒设置；这里解决旧 `f50.iot` 流量池页面固定每20分钟查询的问题。

## 更新内容

- 「蜂窝 → 流量池 → 小鲸 IoT 自动校正」新增刷新间隔，填写 **5–1440 的整数分钟**，默认20分钟。
- 在原同步按钮旁紧凑显示「每 [20] 分钟 [保存]」，不增加设置区块；保存带确认提示，前后端同时校验，防重复提交，页面轮询不覆盖正在输入的间隔。
- 配置写入原私有文件的 `interval_seconds` 字段，保留卡号、验证码、SIM绑定和未知字段；不修改套餐额度或每日/月度历史。
- 使用原校正任务锁，避免保存与校正并发；原子写入，文件权限0600。
- 自动任务每5秒重新读取间隔；从最近查询尝试/成功时间计算是否到期。修改间隔本身不查询运营商，缩短后若已到期则在后续调度中正常查询。
- 旧配置没有新字段时仍为1200秒，数据过期提示改为配置间隔加5分钟宽限。

## 使用边界

仅适用于同时具有以下文件/接口的旧集成版本：

- `/usr/libexec/f50-xiaojing-sync.rb`
- `/usr/libexec/rpcd/f50.iot`（get/sync）
- `/www/luci-static/resources/view/mu300/traffic.js`
- `/usr/share/rpcd/acl.d/luci-app-f50-iot.json`

补丁检查已知代码锚点，不匹配、重复应用会拒绝；**没有为任意新固件自动兼容**。不得和独立插件同时启用两个校正后台。

在开发电脑建立以上四个文件的离线目录副本，然后执行：

```sh
python3 tools/apply_mu300_interval.py /path/to/staged-root
```

工具先检查全部文件，再生成修改后的四个文件及新增的 `/usr/libexec/f50-xiaojing-interval.rb`。不包含卡号配置，不访问设备、不自动上传、不重启服务；不能在路由器 `/` 根目录运行。

维护者应自行备份目标设备、核对文件哈希、检查 Ruby/JS/JSON 语法，再原子部署生成文件。只需重启小鲸后台以载入新调度器，并让 rpcd 重新加载方法与 ACL；不要重启整机或网络。首次升级、卸载和固件升级覆盖需人工核对，补丁不是固件更新持久化机制。

旧集成脚本原先使用 HTTP 查询，本补丁不修改其平台请求和安全许可；不会使旧部署自动获得独立插件的 HTTPS 默认策略。不要公开设备配置或查询凭据。
